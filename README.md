# 简易计算器

一个美观且功能完善的网页版计算器，支持基本的数学运算。

## 功能特点

- 基本四则运算：加、减、乘、除
- 百分比运算
- 清除和删除功能
- 支持键盘输入
- 美观的现代UI设计
- 响应式布局，适配不同屏幕尺寸

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可使用计算器。

2. 或者使用本地服务器运行：
   ```bash
   # 使用Python
   python -m http.server

   # 使用Node.js (需要安装http-server)
   npx http-server
   ```

## 键盘快捷键

- 数字键 (0-9)：输入数字
- 小数点 (.)：输入小数点
- 加号 (+)：加法运算
- 减号 (-)：减法运算
- 乘号 (*)：乘法运算
- 除号 (/)：除法运算
- 等号 (=) 或 Enter：计算结果
- Backspace：删除最后一位数字
- Escape：清除所有输入

## 注意事项

- 除数为零时会显示警告信息
- 计算结果会自动处理浮点数精度问题
- 支持长数字显示，超出范围可横向滚动
